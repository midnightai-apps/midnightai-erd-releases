# Midnight ERD

Design database schemas and turn them into clear diagrams and documentation.

## Download

Get the latest macOS release from [Releases](https://github.com/midnightai-apps/midnightai-erd-releases/releases).

**Mac with Apple silicon** — download the DMG, open it, and drag Midnight ERD into Applications.

## Features

- Design tables, columns, and relationships on an ERD canvas.
- Import existing schemas from MySQL, MariaDB, Microsoft SQL Server, and PostgreSQL.
- Export diagrams and Excel documentation.
- Exchange dictionaries and domains with Excel.
- Connect compatible AI tools through Local MCP.
- Work with projects stored on your Mac.
- Choose English or Korean from the Language menu.

## Updates

Starting with version 1.0.1, Midnight ERD checks for updates and downloads them automatically. Updates are applied after you quit the app.

To check manually, choose **Help → Check for updates**.

If you have version 1.0.0, install the latest DMG once to receive automatic updates.
